# Документация проекта

Документы описывают игровые вводные, текущее устройство прототипа и предлагаемую архитектуру следующих систем.

- [Единый бриф игры](../GAME_BRIEF.md) — концепция, технологии, требования, ограничения и статус.
- [Построение игрового мира](WORLD_AND_SCENE.md) — как формируется сцена, кратер, рельеф, ресурсы, объекты и камера.
- [Система строительства](BUILDING_SYSTEM.md) — рекомендуемая архитектура каталога, предпросмотра, размещения, перемещения, экономики и сохранения.
- [Управление луноходом](ROVER_CONTROL.md) — управление, физическая модель движения, повороты, коллизии и камера.
- [Техническая архитектура и этапы](TECHNICAL_ROADMAP.md) — разделение клиентского прототипа и будущей серверной игры.

## Статус и терминология

В документах различаются:
- **Сейчас в прототипе** — то, что уже присутствует в текущем коде.
- **Предлагаемая реализация** — рекомендуемый способ развить систему.
- **Целевое состояние** — требования, которые ещё предстоит реализовать и проверить.

Числа баланса, не утверждённые владельцем игры, отмечены как предварительные.
